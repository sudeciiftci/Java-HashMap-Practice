Java HashMap Practice

This repository contains Java practice projects focused on HashMap, Collections, and data management.

Projects

1. GameTournamentManager

A console-based tournament management system.

Features:

* Register and remove players
* Display registered players
* Add players to a tournament
* Update player scores
* Display player scores
* Show a leaderboard sorted by score

Topics covered:

* HashMap
* LinkedHashSet
* ArrayList
* Map.Entry
* Comparator
* Sorting with sort() and reversed()
* Scanner
* switch and while loops

2. LogAnalyzer

A simple program that analyzes log messages and counts how many times each log type appears.

Topics covered:

* HashMap
* Arrays
* split()
* getOrDefault()
* put()
* Counting occurrences

3. HashMapPractice

A basic example of storing and updating student grades.

Topics covered:

* HashMap
* put()
* get()
* Updating existing values

Technologies

* Java
* Collections Framework
* HashMap
* LinkedHashSet
* ArrayList
